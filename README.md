# JobShield AI 🛡️

An AI-powered Fake Job Detection and Company Verification Platform.

## Features

- 🔍 AI Job Scam Detection
- 📊 Trust Score Analysis
- 📜 Analysis History
- 🚨 Scam Report Submission
- ✅ Verified Companies Directory
- 👨‍💼 Admin Panel for Company Verification
- 🔐 Firebase Authentication
- 🌙 Dark/Light Theme

## Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS

### Backend
- FastAPI
- Python

### Database
- Firebase Firestore
- Firebase Authentication
